# Simple-Calculator
The Simple Calculator is a Java Swing application that performs basic arithmetic operations — addition, subtraction, multiplication, and division.
It provides a user-friendly GUI with buttons for digits and operators, a display area for inputs and results, and a clear button to reset the calculation.

This project is designed for beginners learning Java GUI development and event-driven programming. It demonstrates how to build interactive desktop applications using Swing components such as JFrame, JButton, and JTextField.
